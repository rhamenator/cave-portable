# CAVE Portable

A lightweight, cross-platform weather viewer inspired by the needs of AWIPS CAVE users. This is an **independent companion**, not a fork or replacement for the full AWIPS CAVE workstation. It runs without an EDEX server and does not issue warnings or its own severe-weather risk outlook.

## What works in 0.4.2

The decoded radar workspace reads current NOAA Level III digital reflectivity, base Doppler velocity, correlation coefficient (CC), differential reflectivity (ZDR), and specific differential phase (KDP) for the selected WSR-88D site. It shows scan time, selectable elevation tilts 0–3, palette, a short scan timeline, geographic zoom and pan, and values at clicked points. Products are matched to the same reflectivity volume; a missing match is shown as unavailable. Dual-pol fields are masked below 10 dBZ reflectivity. Optional SPC Day 1 and local NWS alert boundaries are drawn over the map. The local alert query uses the saved US location, and the map labels the official layer times and nearby airport observation time. Older radar frames explicitly identify current overlays as later data. Low CC has several possible causes and **does not by itself confirm debris**.

The local briefing combines an airport observation and timestamp-based pressure trend, local NWS alert count, SPC point outlook, readable NWS forecast, and three hourly periods. The trend is descriptive and is not a storm-risk score. An on-demand NOAA MRMS MESH readout samples estimated hail size at and near the selected contiguous-US point. Radar also has a mapped 30-minute MRMS MESH maximum. MESH is an algorithmic estimate, not a measured stone size or forecast. The Forecast ingredients tab shows GFS CAPE, CIN, 2 m relative humidity, 2 m dewpoint, surface lifted index, a storm-relative helicity layer, and 500 hPa wind speed for a selected model run and forecast hour. The last two are ingredients, not a computed shear or severe-weather probability.

- National radar composite from NOAA/NWS, single-site reflectivity and storm-relative Doppler velocity from Iowa Environmental Mesonet, NWS hydrometeor classification (including a hail category, but no hail size), and GOES East/West GeoColor satellite imagery from NOAA/NESDIS. The NWS station catalog supplied 159 WSR-88D sites in a live test; the app has a small fallback list. Site views have 1×, 2×, 4×, 8×, and 16× zoom. The station list includes KLAN; selecting it centers the nearby KGRR radar view on Lansing.
- Current METAR observations at 25 US airports, direct ICAO station lookup, raw METAR and TAF, recent station altimeter trend, and active NWS alerts by state.
- Official SPC Day 1–3 categorical convective outlook maps and structured Day 1 point guidance for a selected US station or postal location, with category and tornado/hail/wind probabilities when outlined. Human-readable NWS point forecasts appear for US locations. The app also shows current Southern Plains mixed-layer CAPE analysis, 0–72 hour GFS surface-based CAPE forecasts from NSF Unidata THREDDS, and 3/6/12/18-hour NCEP HRRR simulated reflectivity forecasts via Iowa Mesonet. The GFS and HRRR views use a regional area around the selected location and share +/− zoom controls. The HRRR image is composed with a USGS basemap and labelled with model run and valid times. It is forecast imagery, not observed radar or a severe-weather probability. The SPC outlook is the official severe-risk guidance; CAPE is only one ingredient.
- A required US ZIP or full Canadian postal code for local weather and alerts. An optional small temperature/conditions window uses the nearest reporting airport; opt-in NWS/ECCC warning and watch monitoring uses a postal-area centroid. New warnings use a system bell and message box; watches use a message box. On Linux Wayland, an available system tray indicator shows red for a warning and yellow for a watch. Start at login is optional.
- Background network loading, 60-second refresh for observations/radar/satellite and NWS alerts, source-time checks on imagery, bounded downloads, and no EDEX dependency.

The app is designed to start and remain responsive on machines below the [8 GB minimum](https://unidata.github.io/awips2/install/install-cave/) listed for full CAVE. Resource measurements and wider platform validation are still needed before claiming a specific RAM target. See [Scope and roadmap](docs/ROADMAP.md).

## Install

### Desktop bundles

Tagged builds produce downloadable Windows, macOS Intel/Apple Silicon, and Linux archives on GitHub Releases. These bundles are currently **unsigned**. On Linux, extract the archive and run `sh install-linux.sh` from its extracted folder to install for your user account with a weather icon and application-menu entry. Then launch **CAVE Portable** from the menu or run `~/.local/bin/cave-portable`. Linux Wayland sessions use a native GTK 3 window; Linux X11, Windows, and macOS use Tk. The Linux bundle requires a GTK 3 runtime, which is already present on many desktops. Windows and macOS users can extract and launch `CAVE-Portable.exe` or `CAVE-Portable.app`; those builds also carry the icon. A signed installer and cross-distribution Linux package are planned. The Linux executable uses the build runner's glibc baseline and may not work on older distributions.

### From source (Linux, Windows, macOS)

Install Python 3.10 or later, Tk, and Python's `venv` module. Linux Wayland also needs GTK 3 and PyGObject. On Debian/Ubuntu, install `python3-tk`, `python3-venv`, `python3-gi`, and `gir1.2-gtk-3.0`; on Fedora/RHEL, install `python3-tkinter`, `python3-gobject`, and `gtk3`; on Arch, install `tk`, `python-gobject`, and `gtk3`. When using the distribution's PyGObject package, create the virtual environment with `python3 -m venv --system-site-packages .venv` so Python can import it. Tk and `venv` are included with standard Python installers on Windows and macOS. Then:

```sh
python3 -m venv --system-site-packages .venv
. .venv/bin/activate
python -m pip install .
cave-portable
```

On Windows PowerShell, activate with `.venv\Scripts\Activate.ps1` and run `cave-portable`. No administrator access or EDEX server is required.

## Use

The source tree includes [NOAA historical observation and radar replay tools](docs/NOAA_REPLAY.md) for research. They are separate from the desktop app and do not issue forecasts or alerts.

Choose **Observations**, **Radar**, **Satellite**, **Severe outlook & CAPE**, **Forecast ingredients**, or **HRRR storm forecast**. Select a station in the observations table to read the raw METAR and set the nearby radar and forecast area. KLAN is included; select it and choose **View nearest radar** (or double-click it) for a Lansing-centered KGRR radar view. Enter a four-character ICAO code and choose **Load station** for the latest METAR and TAF. Enter a two-letter US state code for active NWS alerts. In Radar, choose a national mosaic, a decoded site product with Tilt 0–3, a 30-minute MRMS hail estimate, or the older upstream site imagery; use the +/− buttons or keys to zoom. The same controls zoom regional GFS and HRRR maps. Select Day 1, 2, or 3 to see SPC's forecast severe weather areas. The selected US point also shows current SPC Day 1 category and tornado/hail/wind percentages where outlined, with issue and valid times, plus a readable NWS forecast. **Southern Plains MLCAPE** is a regional analysis; **Forecast ingredients** selects an explicit GFS run, field, and forecast hour. **HRRR storm forecast** shows simulated future reflectivity, with run and valid times. See [weather data and forecast image plan](docs/DATA_SOURCES.md), [station risk replay](docs/STATION_BACKTEST.md), [Mesonet archive replay](docs/MESONET_ARCHIVE.md), and [CAVE capability research](docs/CAVE_RESEARCH.md) for source differences and limits.

For local weather and alerts, choose **US** or **CA**, enter a valid five-digit ZIP (ZIP+4 accepted) or a full six-character Canadian postal code, optionally enter a street address, and choose **Set ZIP / postal code**. The app never infers location from an IP address. The mini window labels temperature and conditions as a nearby airport observation, including station and observation time. Select **Monitor official warnings and watches at postal area** to poll NWS or ECCC weather alerts every minute while running. A new warning rings the system bell and opens a message box; a watch opens a message box without the bell. **Start at login** registers only this user's login startup entry. These options are off by default and require a set postal location. On Linux Wayland, **Minimize to tray** hides the main window if the desktop offers an AppIndicator service; the tray menu can reopen it or quit. Closing the main window quits the app and stops the monitor. The tray indicator depends on desktop support and is not available in the Tk interface used on Windows, macOS, and Linux X11.

Without a street address, the US lookup uses the ZIP centroid. Canadian postal lookup uses only the first three characters (the forward sortation area, or FSA) and its centroid, even though entering the full code is required. A street address refines US coordinates through the US Census geocoder or Canadian coordinates through Natural Resources Canada's Geolocator. These geocodes are still **approximations** and may differ from your address or an alert polygon boundary. The weather bug reports airport weather, which may differ from conditions at your location. Europe coverage is planned only if suitable live weather and official alert data can be verified.

Weather data can be delayed, missing, or unavailable. The app refuses radar scans and national radar imagery older than 15 minutes, and satellite imagery older than 30 minutes. It shows the source timestamp; forecasts and outlooks have separate valid times. The alert monitor is an internet-dependent API client, **not an Emergency Alert System (EAS) or Wireless Emergency Alerts (WEA) receiver**. It cannot guarantee delivery or audibility. This software is for education and situational awareness. **For shelter decisions, use [weather.gov](https://www.weather.gov/) in the US, [weather.gc.ca](https://weather.gc.ca/) in Canada, mobile emergency alerts, weather radio, and official local instructions.** The GPL license includes a no-warranty clause.

Other public-safety alerts, including AMBER alerts, are not available in the current weather-only feeds. See [Alert coverage and limits](docs/ALERTS.md) for the US/Canada distinction and the planned opt-in AMBER category.

## Data and network

The application sends read-only HTTPS requests to NOAA/NWS/NESDIS/SPC, public NOAA NEXRAD/MRMS S3 buckets, ECCC, Zippopotam.us, US Census, Natural Resources Canada, NSF Unidata THREDDS, USGS, and Iowa Environmental Mesonet endpoints in [data.py](src/cave_portable/data.py), [location.py](src/cave_portable/location.py), [model.py](src/cave_portable/model.py), [radar.py](src/cave_portable/radar.py), [hrrr.py](src/cave_portable/hrrr.py), [spc.py](src/cave_portable/spc.py), [level3.py](src/cave_portable/level3.py), [mrms.py](src/cave_portable/mrms.py), and [overlays.py](src/cave_portable/overlays.py). The first five ZIP digits or first three Canadian postal characters are sent to Zippopotam.us for geocoding; the full Canadian code is not sent there. If entered, the street address and ZIP are sent to US Census, or the street, locality, and province are sent to Natural Resources Canada. A nearby bounding box or selected station code is sent to NOAA Aviation Weather Center; the selected airport code is also sent there for a four-hour METAR history. Selected US coordinates are sent to SPC's vector outlook service and the NWS point forecast API; regional map bounds are sent to model and radar image services. When local monitoring is enabled, geocoded coordinates are sent to the NWS or ECCC alert endpoint. There is no telemetry or API key. Country, postal code, optional street address, selected station, and monitor preference are stored in a user settings file; weather data is not cached on disk. Network requests have a 12-second timeout and response size limits. Imagery is shown with the source's own legend and valid time when present. Stale or failed images are cleared and an error is shown.

Sources: [Zippopotam.us](https://docs.zippopotam.us/docs/getting-started/), [US Census Geocoder](https://geocoding.geo.census.gov/geocoder/Geocoding_Services_API.html/), [Natural Resources Canada Geolocator](https://natural-resources.canada.ca/maps-tools-publications/satellite-elevation-air-photos/geolocation-service), [NOAA Aviation Weather Center API](https://aviationweather.gov/data/api/), [NWS Alerts API](https://www.weather.gov/documentation/services-web-api), [ECCC OGC API](https://eccc-msc.github.io/open-data/msc-geomet/ogc_api_en/), [NWS radar](https://radar.weather.gov/), [NOAA GOES imagery](https://www.star.nesdis.noaa.gov/GOES/), [SPC convective outlooks](https://www.spc.noaa.gov/products/outlook/), [SPC mesoanalysis](https://www.spc.noaa.gov/exper/mesoanalysis/), [NSF Unidata THREDDS](https://www.unidata.ucar.edu/data/nsf-unidatas-thredds-data-server), [USGS National Map](https://www.usgs.gov/programs/national-geospatial-program/national-map), [Iowa Environmental Mesonet OGC services](https://mesonet.agron.iastate.edu/ogc/), and [IEM HRRR model imagery](https://mesonet.agron.iastate.edu/GIS/model.phtml).
